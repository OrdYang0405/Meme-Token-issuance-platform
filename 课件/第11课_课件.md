## 二、知识回顾（5 分钟）

**Q1：MemeToken 的税费在什么条件下触发？买入和卖出分别扣什么税？**

> 答案：`contracts/MemeToken.sol:151-154`——只有当 `from` 或 `to` 为 `uniswapV2Pair` 时才扣税。`to == pair` 是卖出（扣 sellTax），`from == pair` 是买入（扣 buyTax）。普通转账不扣税。

**Q2：Uniswap V2 的恒定乘积公式是什么？用 1 ETH 买入代币能获得多少？**

> 答案：`x × y = k`，其中 x 为池中 ETH 量，y 为池中代币量。用 Δx 个 ETH 买入，获得：`Δy = (y × Δx) / (x + Δx)`。注意这不是最终公式——Uniswap 还会扣除 0.3% 的手续费，而且 MemeToken 还有额外的买入税。

**Q3：`swapExactTokensForETHSupportingFeeOnTransferTokens` 和普通的 `swapExactTokensForETH` 有什么区别？**

> 答案：`contracts/MemeToken.sol:13-19` 声明了这个接口。普通版本假设 `amountIn` 的全部到达 Pair；而 `SupportingFeeOnTransferTokens` 版本会检查 Pair 的实际余额变化来确定真实转入量。因为 MemeToken 有转账税费——用户卖出 1000 个代币，实际只有 950 个到达 Pair（扣了 5% 的税），普通版本会按 1000 计算导致交易失败。

**引入**：第9课我们完成了 Uniswap 的合约端集成（Router、Pair、SwapAndLiquify），但用户要在哪里实际买卖代币？本课将实现交易页面——用户输入金额、看到实时报价、一键完成买入/卖出。

## 四、代币选择器与搜索（15 分钟）

### 4.1 代币列表的数据来源

交易页面需要展示"可交易的代币"列表。数据可以从两个来源获取：

| 来源 | 方法 | 优点 | 缺点 |
|------|------|------|------|
| MemeFactory | `getTokensPaginated(offset, limit)` | 完备、已实现 | 只有通过 Factory 创建的代币 |
| 用户自定义 | 手动输入代币地址 | 支持任意 ERC20 | 用户需要知道地址 |
| 链上事件 | 监听 `PairCreated` 事件 | 包含所有 Uniswap 代币 | 需索引大量区块 |

本课以 **MemeFactory + 手动输入** 为主，覆盖最常用的场景。

### 4.2 代币元数据获取

```typescript
// 文件：frontend/src/swap/tokenSearch.ts

import { BrowserProvider, Contract, formatEther } from "ethers";

// ERC20 最小 ABI——获取名称、符号、精度
const ERC20_METADATA_ABI = [
    "function name() view returns (string)",
    "function symbol() view returns (string)",
    "function decimals() view returns (uint8)",
];

// 带缓存的代币元数据
const metadataCache = new Map<string, TokenMetadata>();

export interface TokenMetadata {
    address: string;
    name: string;
    symbol: string;
    decimals: number;
}

/**
 * 批量获取代币元数据（利用 Promise.all 并行请求）
 */
export async function fetchTokenMetadataBatch(
    provider: BrowserProvider,
    addresses: string[]
): Promise<Map<string, TokenMetadata>> {
    // 分离已缓存和未缓存
    const uncached = addresses.filter(a => !metadataCache.has(a.toLowerCase()));
    const result = new Map<string, TokenMetadata>();

    // 已缓存的直接返回
    for (const addr of addresses) {
        const cached = metadataCache.get(addr.toLowerCase());
        if (cached) result.set(addr, cached);
    }

    if (uncached.length === 0) return result;

    // 并行获取未缓存的代币元数据
    const metadata: TokenMetadata[] = await Promise.all(
        uncached.map(async (addr) => {
            try {
                const token = new Contract(addr, ERC20_METADATA_ABI, provider);
                const [name, symbol, decimals] = await Promise.all([
                    token.name(),
                    token.symbol(),
                    token.decimals(),
                ]);
                const meta: TokenMetadata = {
                    address: addr,
                    name,
                    symbol,
                    decimals: Number(decimals),
                };
                // 写入缓存
                metadataCache.set(addr.toLowerCase(), meta);
                return meta;
            } catch {
                // 如果地址不是 ERC20，返回占位符
                return {
                    address: addr,
                    name: "Unknown Token",
                    symbol: "???",
                    decimals: 18,
                };
            }
        })
    );

    for (const meta of metadata) {
        result.set(meta.address, meta);
    }
    return result;
}

/**
 * 获取所有可交易的代币列表（从 MemeFactory + 常用代币）
 */
export async function getTradeableTokens(
    factory: Contract,
    provider: BrowserProvider
): Promise<TokenMetadata[]> {
    // 从 Factory 获取所有已创建的代币
    const total = Number(await factory.totalTokens());
    const { tokens } = await factory.getTokensPaginated(0, Math.min(total, 500));

    // 批量获取元数据
    const metaMap = await fetchTokenMetadataBatch(provider, tokens);
    return Array.from(metaMap.values());
}
```

> **课堂提问**：为什么 ETH 不能用普通的 ERC20 ABI 来获取元数据？
>
> **答案**：ETH 是以太坊的原生资产，它不是 ERC20 合约——没有 `name()`、`symbol()`、`decimals()` 函数，也没有 `transfer()`（ETH 转账用的是 `transfer` 操作码）。在 Uniswap 中，ETH 通过 WETH（Wrapped ETH）来参与交易——Router 内部自动将 ETH 包装成 WETH 或从 WETH 解包。前端需要将 ETH 作为特殊情况处理。

## 五、链上报价引擎（25 分钟）

### 5.1 Router 的报价函数

Uniswap V2 Router 提供了两组报价函数：

```solidity
// ─── 正向报价：给定输入量，计算输出量 ───
function getAmountsOut(
    uint amountIn,
    address[] calldata path
) external view returns (uint[] memory amounts);
// amounts[0] = amountIn
// amounts[1] = 经过第一跳后的输出量
// amounts[2] = 经过第二跳后的输出量
// ...

// ─── 反向报价：给定期望输出量，计算需要多少输入量 ───
function getAmountsIn(
    uint amountOut,
    address[] calldata path
) external view returns (uint[] memory amounts);
// amounts[0] = 所需的输入量
// amounts[1] = amountOut
```

**path 参数详解**：

```
ETH → TOKEN 买入:
  path = [WETH地址, TOKEN地址]

TOKEN → ETH 卖出:
  path = [TOKEN地址, WETH地址]

TOKEN A → TOKEN B（两跳）:
  path = [TOKEN_A, WETH, TOKEN_B]
  先 A → WETH，再 WETH → B
```

### 5.2 报价引擎实现

```typescript
// 文件：frontend/src/swap/swap.ts（报价部分）

import { BrowserProvider, Contract, formatEther, parseEther } from "ethers";

// ============ Router 完整 ABI（交易页面需要的部分）============

const ROUTER_ABI = [
    // 报价
    "function getAmountsOut(uint amountIn, address[] path) view returns (uint[])",
    "function getAmountsIn(uint amountOut, address[] path) view returns (uint[])",
    // 交易
    "function swapExactETHForTokens(uint amountOutMin, address[] path, address to, uint deadline) payable returns (uint[])",
    "function swapExactTokensForETH(uint amountIn, uint amountOutMin, address[] path, address to, uint deadline) returns (uint[])",
    "function swapExactETHForTokensSupportingFeeOnTransferTokens(uint amountOutMin, address[] path, address to, uint deadline) payable",
    "function swapExactTokensForETHSupportingFeeOnTransferTokens(uint amountIn, uint amountOutMin, address[] path, address to, uint deadline)",
    // 基础查询
    "function WETH() view returns (address)",
    "function factory() view returns (address)",
];

// ============ Pair 最小 ABI（直接查询储备量）============

const PAIR_ABI = [
    "function getReserves() view returns (uint112 reserve0, uint112 reserve1, uint32 blockTimestampLast)",
    "function token0() view returns (address)",
    "function token1() view returns (address)",
];

// ============ 报价请求类型 ============

export interface QuoteRequest {
    tokenIn: string;     // 输入代币地址
    tokenOut: string;    // 输出代币地址
    amountIn: bigint;    // 输入量（以最小单位计）
    slippagePercent: number; // 滑点百分比，如 0.5 表示 0.5%
}

export interface QuoteResult {
    amountOut: bigint;          // 预期输出量
    amountOutMin: bigint;       // 最小输出量（考虑滑点）
    executionPrice: number;     // 实际成交价（tokenOut / tokenIn）
    spotPrice: number;          // 即时价格（交易前）
    priceImpact: number;        // 价格冲击百分比
    priceImpactLevel: "low" | "medium" | "high" | "extreme";
    path: string[];             // 交易路径
    feeOnTransfer: boolean;     // 是否涉及 fee-on-transfer 代币
}

/**
 * 获取交易报价
 *
 * 工作流程：
 * 1. 构建 path（ETH 用 WETH 替代）
 * 2. 调用 Router.getAmountsOut → 获取预期输出
 * 3. 查询 Pair reserves → 计算即时价格
 * 4. 计算价格冲击 = (spotPrice - executionPrice) / spotPrice
 * 5. 应用滑点 → amountOutMin
 */
export async function getSwapQuote(
    provider: BrowserProvider,
    router: Contract,
    weth: string,
    request: QuoteRequest
): Promise<QuoteResult> {
    // ── 步骤 1：构建 path ──
    const tokenIn = request.tokenIn === NATIVE_ETH.address ? weth : request.tokenIn;
    const tokenOut = request.tokenOut === NATIVE_ETH.address ? weth : request.tokenOut;
    const path = [tokenIn, tokenOut];

    // ── 步骤 2：调用 Router 获取报价 ──
    const amounts: bigint[] = await router.getAmountsOut(request.amountIn, path);
    const amountOut = amounts[amounts.length - 1];

    if (amountOut === 0n) {
        throw new Error("交易路径无流动性，输出量为 0");
    }

    // ── 步骤 3：查询 Pair reserves 计算即时价格 ──
    const factoryAddr: string = await router.factory();
    const factory = new Contract(factoryAddr,
        ["function getPair(address,address) view returns (address)"],
        provider
    );
    const pairAddr = await factory.getPair(tokenIn, tokenOut);
    const pair = new Contract(pairAddr, PAIR_ABI, provider);
    const reserves = await pair.getReserves();
    const token0 = await pair.token0();

    // 根据 token 排序确定 reserve0/reserve1 对应关系
    let reserveIn: bigint, reserveOut: bigint;
    if (tokenIn.toLowerCase() < tokenOut.toLowerCase()) {
        // tokenIn = token0
        reserveIn = reserves[0];
        reserveOut = reserves[1];
    } else {
        // tokenIn = token1
        reserveIn = reserves[1];
        reserveOut = reserves[0];
    }

    // ── 步骤 4：计算价格冲击 ──
    // 即时价格 = reserveOut / reserveIn（交易前 1 tokenIn = ? tokenOut）
    const spotPrice = Number(reserveOut) / Number(reserveIn);

    // 实际成交价 = amountOut / amountIn
    const executionPrice = Number(amountOut) / Number(request.amountIn);

    // 价格冲击 = (spotPrice - executionPrice) / spotPrice
    const priceImpact = spotPrice > 0
        ? ((spotPrice - executionPrice) / spotPrice) * 100
        : 0;

    // ── 步骤 5：应用滑点保护 ──
    const slippageFactor = (10000 - request.slippagePercent * 100) / 10000;
    const amountOutMin = BigInt(Math.floor(Number(amountOut) * slippageFactor));

    return {
        amountOut,
        amountOutMin,
        executionPrice,
        spotPrice,
        priceImpact,
        priceImpactLevel: getPriceImpactLevel(priceImpact),
        path,
        feeOnTransfer: true, // MemeToken 有转账税费
    };
}

/**
 * 反向报价：我想获得 exactAmountOut，需要支付多少？
 * 适用于"Buy"方向——用户指定想买多少代币
 */
export async function getSwapQuoteIn(
    provider: BrowserProvider,
    router: Contract,
    weth: string,
    tokenIn: string,
    tokenOut: string,
    amountOut: bigint,
    slippagePercent: number
): Promise<{ amountIn: bigint; amountInMax: bigint }> {
    const _tokenIn = tokenIn === NATIVE_ETH.address ? weth : tokenIn;
    const _tokenOut = tokenOut === NATIVE_ETH.address ? weth : tokenOut;
    const path = [_tokenIn, _tokenOut];

    const amounts: bigint[] = await router.getAmountsIn(amountOut, path);
    const amountIn = amounts[0];

    // 反向滑点：允许最多多付 (1 + slippage%)
    const slippageFactor = (10000 + slippagePercent * 100) / 10000;
    const amountInMax = BigInt(Math.ceil(Number(amountIn) * slippageFactor));

    return { amountIn, amountInMax };
}
```

### 5.3 价格冲击等级判定

```typescript
// 文件：frontend/src/swap/priceImpact.ts

export type ImpactLevel = "low" | "medium" | "high" | "extreme";

/**
 * 根据价格冲击百分比判定风险等级
 *
 * 阈值参考 Uniswap 前端：
 * - < 1%: 正常，绿色
 * - 1%-3%: 中等，橙色警告
 * - 3%-5%: 高，红色警告
 * - > 5%: 极端，强烈警告
 */
export function getPriceImpactLevel(impactPercent: number): ImpactLevel {
    if (impactPercent < 1) return "low";
    if (impactPercent < 3) return "medium";
    if (impactPercent < 5) return "high";
    return "extreme";
}

export const IMPACT_STYLES: Record<ImpactLevel, { color: string; label: string }> = {
    low:     { color: "#4CAF50", label: "低" },
    medium:  { color: "#FF9800", label: "中等" },
    high:    { color: "#F44336", label: "高" },
    extreme: { color: "#B71C1C", label: "极高" },
};

export function formatPriceImpact(impactPercent: number): string {
    if (impactPercent < 0.01) return "< 0.01%";
    return `${impactPercent.toFixed(2)}%`;
}
```

> **课堂提问**：为什么价格冲击在 3% 时要给用户警告？价格冲击大意味着什么？
>
> **答案**：价格冲击大意味着用户的交易量相对于池子的深度过大，会显著推动价格。这不仅意味着用户自身的成交价变差，还意味着用户很容易被 MEV 攻击——攻击者在用户交易前抢先买入推高价格（front-run），用户成交后再卖出（back-run），从用户的滑点中获利（sandwich attack）。**对于 Meme 代币而言，早期流动性通常很小，价格冲击是最需要关注的风险指标之一。**

### 5.4 报价中的 MemeToken 税费影响

由于 MemeToken 的 fee-on-transfer 特性，`getAmountsOut` 的报价是**税费前**的估值——它假设 `amountIn` 全部到达 Pair。但实际交易中：

```
买入（ETH → TOKEN）：
  用户支付 1 ETH → Pair 收到 1 ETH（ETH 没有税费）
  但是 Pair 转出的 TOKEN 经过了 Uniswap 的 0.3% 手续费
  代币到达用户钱包时不触发税费（from = Pair, to = 用户）
  由于 MemeToken.sol:151 的条件是 from == pair || to == pair
  而 from == pair → shouldTakeFee = true!
  等一等，需要仔细分析：

买入场景：
  from = Pair, to = 用户
  shouldTakeFee = !_inSwap && !isExcludedFromFee[pair] && !isExcludedFromFee[user]
                 && (pair == pair || user == pair)  → true
  isSell = (to == pair) = false → buyTax
  所以买入要扣 buyTax！
  
  这意味着用户通过 Uniswap 买入时：
  1. Uniswap 按恒定乘积计算出 amountOut
  2. 但是 amountOut 在到达用户钱包前会触发 _update(Pair, user, amountOut)
  3. 扣掉 buyTax 后实际到手的代币 = amountOut * (1 - buyTax/10000)
  
  所以 getAmountsOut 返回的值需要手动扣除买入税！

卖出场景（TOKEN → ETH）：
  用户卖出代币，from = 用户, to = Pair
  shouldTakeFee = true, isSell = true → sellTax
  Router 调用 swapExactTokensForETHSupportingFeeOnTransferTokens
  这个函数内部会检测 Pair 实际收到的代币量（卖出税后）

前端需要特殊处理：
- 买入报价 = getAmountsOut / (1 - buyTax/10000)（显示实际到手量）
- 卖出报价 = getAmountsOut（Router 自动处理，但用户实际支付 = amountIn + sellTax）
```

```typescript
/**
 * 针对 MemeToken 的报价修正
 *
 * 因为 MemeToken 在转账时扣税：
 * - 买入（Pair → 用户）：用户实际收到的 = Uniswap 输出 × (1 - buyTax)
 * - 卖出（用户 → Pair）：实际到达 Pair 的 = 用户输入 × (1 - sellTax)
 *
 * 普通的 getAmountsOut 不知道税费，所以前端需要手动修正报价
 */
export async function getMemeTokenQuote(
    provider: BrowserProvider,
    router: Contract,
    weth: string,
    token: Contract,          // MemeToken 合约实例
    request: QuoteRequest,
    direction: "buy" | "sell"
): Promise<QuoteResult> {
    // 获取基础报价
    const baseQuote = await getSwapQuote(provider, router, weth, request);

    let adjustedAmountOut = baseQuote.amountOut;

    if (direction === "buy") {
        // 买入：扣除买入税后的实际到手量
        const buyTax: bigint = await token.buyTax();
        // 实际到手 = Uniswap输出 × (10000 - buyTax) / 10000
        adjustedAmountOut = baseQuote.amountOut * (10000n - buyTax) / 10000n;
    }
    // 卖出时 Router 使用 SupportingFeeOnTransferTokens 变体，
    // 会自动处理税费——前端报价保持不变，但用户需要知道实际支付 = amountIn + tax

    return {
        ...baseQuote,
        amountOut: adjustedAmountOut,
        amountOutMin: BigInt(Math.floor(Number(adjustedAmountOut) *
                        (10000 - request.slippagePercent * 100) / 10000)),
    };
}
```

### 6.1 ETH → Token 买入

```typescript
// 文件：frontend/src/swap/swap.ts（交易执行部分）

export interface SwapParams {
    router: Contract;
    tokenIn: string;           // 输入代币地址（ETH = NATIVE_ETH.address）
    tokenOut: string;          // 输出代币地址
    amountIn: bigint;          // 输入量（wei）
    amountOutMin: bigint;      // 最小输出量
    recipient: string;         // 接收地址
    deadline: number;          // 交易截止时间戳
    isFeeOnTransfer: boolean;  // 是否使用 SupportingFeeOnTransferTokens 变体
}

/**
 * ETH → Token 买入
 *
 * Router 函数签名：
 *   swapExactETHForTokens(
 *       uint amountOutMin,
 *       address[] path,
 *       address to,
 *       uint deadline
 *   ) payable returns (uint[] amounts)
 *
 * 或对于 fee-on-transfer 代币：
 *   swapExactETHForTokensSupportingFeeOnTransferTokens(
 *       uint amountOutMin,
 *       address[] path,
 *       address to,
 *       uint deadline
 *   ) payable
 */
export async function swapETHForTokens(
    router: Contract,
    weth: string,
    params: SwapParams
): Promise<{ txHash: string; amountOut: bigint }> {
    const path = [weth, params.tokenOut];

    // amountOutMin 必须是实际到手的代币量（扣除买入税后）
    let tx;
    if (params.isFeeOnTransfer) {
        tx = await router.swapExactETHForTokensSupportingFeeOnTransferTokens(
            params.amountOutMin,
            path,
            params.recipient,
            params.deadline,
            { value: params.amountIn }   // 附带 ETH
        );
    } else {
        tx = await router.swapExactETHForTokens(
            params.amountOutMin,
            path,
            params.recipient,
            params.deadline,
            { value: params.amountIn }
        );
    }

    console.log("买入交易已广播:", tx.hash);
    const receipt = await tx.wait();

    // 从 Transfer 事件中解析实际收到的代币量
    let amountOut = 0n;
    for (const log of receipt.logs) {
        if (log.address.toLowerCase() === params.tokenOut.toLowerCase()) {
            try {
                // ERC20 Transfer 事件: Transfer(from, to, value)
                // topics[0] = keccak("Transfer(address,address,uint256)")
                // topics[1] = from (indexed), topics[2] = to (indexed)
                // data = value
                const to = "0x" + log.topics[2].slice(26); // 提取 address
                if (to.toLowerCase() === params.recipient.toLowerCase()) {
                    amountOut = BigInt(log.data);
                    break;
                }
            } catch { continue; }
        }
    }

    return {
        txHash: tx.hash,
        amountOut,
    };
}
```

### 6.2 Token → ETH 卖出

```typescript
/**
 * Token → ETH 卖出
 *
 * Router 函数签名：
 *   swapExactTokensForETHSupportingFeeOnTransferTokens(
 *       uint amountIn,
 *       uint amountOutMin,
 *       address[] path,
 *       address to,
 *       uint deadline
 *   )
 *
 * 注意：调用前需要 approve Router 使用代币！
 */
export async function swapTokensForETH(
    router: Contract,
    weth: string,
    token: Contract, // MemeToken 合约实例（需要先 approve）
    params: SwapParams
): Promise<{ txHash: string; amountOut: bigint; ethReceived: bigint }> {
    const path = [params.tokenOut, weth]; // 卖出路径：TOKEN → WETH

    // ═══ 步骤 1：approve Router ═══
    const approveTx = await token.approve(
        await router.getAddress(),
        params.amountIn
    );
    await approveTx.wait();
    console.log("approve 已确认");

    // ═══ 步骤 2：执行卖出 ═══
    // 注意：卖出 fee-on-transfer 代币必须用 SupportingFeeOnTransferTokens 变体
    // 普通 swapExactTokensForETH 会失败——因为实际到 Pair 的量少于 amountIn
    const tx = await router.swapExactTokensForETHSupportingFeeOnTransferTokens(
        params.amountIn,
        params.amountOutMin,
        path,
        params.recipient,
        params.deadline
    );

    console.log("卖出交易已广播:", tx.hash);
    const receipt = await tx.wait();

    // ═══ 步骤 3：计算实际获得的 ETH ═══
    // 获取交易前后的余额差
    // 或者从 receipt 中读取用户地址的 ETH 转入（更准确）
    const ethReceived = receipt.logs
        .filter((log: any) => log.address === weth)
        .reduce((sum: bigint, log: any) => {
            // WETH Withdrawal 事件: Withdrawal(address src, uint wad)
            // 实际发送 ETH 用 call{value}，不在 receipt 中直接体现
            // 用 balance 变化来计算
            return sum;
        }, 0n);

    return {
        txHash: tx.hash,
        amountOut: ethReceived,
        ethReceived,
    };
}
```

```typescript
export enum SwapState {
    IDLE = "IDLE",                   // 初始状态，等待用户输入
    QUOTING = "QUOTING",             // 正在获取报价

    AWAITING_SWAP = "AWAITING_SWAP", // 等待用户在 MetaMask 中确认 swap
    SWAP_PENDING = "SWAP_PENDING",   // swap 交易已广播，等待打包

    FAILED = "FAILED",               // 交易失败
}

export interface SwapStateMachine {
    state: SwapState;
    quote: QuoteResult | null;
    error: string | null;
    txHash: string | null;
    amountOut: bigint | null;
}

/**
 * 状态转换规则
 *
 * IDLE ──[用户输入]──→ QUOTING
 * QUOTING ──[报价完成]──→ QUOTE_READY
 * QUOTING ──[报价失败]──→ IDLE (显示错误)

 * QUOTE_READY ──[用户点击Swap]──→ AWAITING_APPROVAL (如果需 approve)

 *
 * AWAITING_APPROVAL ──[approve确认]──→ AWAITING_SWAP
 * AWAITING_APPROVAL ──[用户拒绝]──→ QUOTE_READY
 *
 * AWAITING_SWAP ──[用户确认]──→ SWAP_PENDING
 * AWAITING_SWAP ──[用户拒绝]──→ QUOTE_READY
 *
 * SWAP_PENDING ──[区块确认]──→ SWAP_CONFIRMED
 * SWAP_PENDING ──[交易revert]──→ FAILED
 *
 * SWAP_CONFIRMED ──[用户关闭]──→ IDLE
 * FAILED ──[用户重试]──→ QUOTING
 */
export function getButtonText(state: SwapState): string {
    switch (state) {
        case SwapState.IDLE:              return "输入金额";
        case SwapState.QUOTING:           return "获取报价中...";
        case SwapState.QUOTE_READY:       return "Swap";
        case SwapState.AWAITING_APPROVAL: return "请在 MetaMask 中确认授权...";
        case SwapState.AWAITING_SWAP:     return "请在 MetaMask 中确认交易...";
        case SwapState.SWAP_PENDING:      return "交易确认中...";
        case SwapState.SWAP_CONFIRMED:    return "交易完成 ✓";
        case SwapState.FAILED:            return "重试";
    }
}

export function isButtonDisabled(state: SwapState): boolean {
    return state === SwapState.IDLE ||
           state === SwapState.QUOTING ||
           state === SwapState.AWAITING_APPROVAL ||
           state === SwapState.AWAITING_SWAP ||
           state === SwapState.SWAP_PENDING;
}
```

### 6.4 完整的 Swap 流程入口

```typescript
/**
 * 执行 Swap 的完整流程
 *
 * 整合了：报价确认 → approve（如需）→ swap → 状态流转
 */
export async function executeSwap(
    state: SwapStateMachine,
    provider: BrowserProvider,
    routerAddress: string,
    token: Contract,       // MemeToken
    params: SwapParams,
    onStateChange: (state: SwapStateMachine) => void
): Promise<void> {
    const signer = await provider.getSigner();
    const router = new Contract(routerAddress, ROUTER_ABI, signer);
    const userAddr = await signer.getAddress();

    try {
        // ═══ 阶段 1：如果是卖出，先 approve ═══
        if (params.tokenIn !== NATIVE_ETH.address) {
            onStateChange({ ...state, state: SwapState.AWAITING_APPROVAL, error: null });

            const approveTx = await token.approve(routerAddress, params.amountIn);
            await approveTx.wait(); // 等待 approve 确认
        }

        // ═══ 阶段 2：执行 swap ═══
        onStateChange({ ...state, state: SwapState.AWAITING_SWAP, error: null });

        let txHash: string;
        if (params.tokenIn === NATIVE_ETH.address) {
            // 买入：ETH → Token
            const result = await swapETHForTokens(
                router, await router.WETH(), params
            );
            txHash = result.txHash;
        } else {
            // 卖出：Token → ETH
            const result = await swapTokensForETH(
                router, await router.WETH(), token, params
            );
            txHash = result.txHash;
        }

        // ═══ 阶段 3：确认中 ═══
        onStateChange({
            ...state,
            state: SwapState.SWAP_PENDING,
            txHash,
            error: null,
        });

        // wait 在 swapTokensForETH / swapETHForTokens 内部已完成
        // 这里直接进入确认状态

        onStateChange({
            ...state,
            state: SwapState.SWAP_CONFIRMED,
            txHash,
            error: null,
        });

    } catch (err: any) {
        if (err.code === "ACTION_REJECTED" || err.code === 4001) {
            // 用户取消 → 回到报价就绪状态
            onStateChange({
                ...state,
                state: SwapState.QUOTE_READY,
                error: null,
            });
        } else {
            onStateChange({
                ...state,
                state: SwapState.FAILED,
                error: err.shortMessage || err.message || "交易失败",
            });
        }
    }
}
```

```typescript
/**
 * 估算 swap 交易的 Gas 费用
 *
 * Gas 估算在以下情况会失败：
 * - 交易一定会 revert（如输入量超过余额）
 * - amountOutMin 设置太高（实际成交永远达不到）
 */
export async function estimateSwapGas(
    router: Contract,
    weth: string,
    params: SwapParams
): Promise<bigint | null> {
    try {
        let gasEstimate: bigint;

        if (params.tokenIn === NATIVE_ETH.address) {
            const path = [weth, params.tokenOut];
            if (params.isFeeOnTransfer) {
                gasEstimate = await router.swapExactETHForTokensSupportingFeeOnTransferTokens
                    .estimateGas(params.amountOutMin, path, params.recipient, params.deadline,
                                 { value: params.amountIn });
            } else {
                gasEstimate = await router.swapExactETHForTokens
                    .estimateGas(params.amountOutMin, path, params.recipient, params.deadline,
                                 { value: params.amountIn });
            }
        } else {
            const path = [params.tokenOut, weth];
            gasEstimate = await router.swapExactTokensForETHSupportingFeeOnTransferTokens
                .estimateGas(params.amountIn, params.amountOutMin, path, params.recipient, params.deadline);
        }

        return gasEstimate;
    } catch (err) {
        console.error("Gas 估算失败:", err);
        return null; // null 表示估算失败，交易可能也会失败
    }
}
```
